# Glossary
- Skill:    How to do something (instruction manual)
- SubAgent: Who does it (code reviewer, tester)
- Hook:     When to act (before/after events, guardrails)

## Skills
Capabilities:
- Create: create skill, create test cases, show results in browser based reviewer to give feedback
- Improve Existing: run test prompts and compare against baseline, run benchmarks, identify what is not working and revise
- Optimize Descriptions: optimize skill descriptions
- Package: bundle into .skill file for easy sharing/installation
