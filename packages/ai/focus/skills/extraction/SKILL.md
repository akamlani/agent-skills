# Analysis
Analyzes and extracts key information from various data sources

## Workflow
1. Use the `AskUserQuestions` tool to receive input data and clarity what type of data it is
2. Use @references/extraction.md for performing extractive summarization in a structured response from the provided context content.
3. Dump the content in a clear human-readable format, such as in partially noted dataframe format


### Additional Considerations
Use the following additional considerations to guide the analysis process:
```
1.  Core Messaging/Main Narrative
2.  Key Themes, Key Points, Key Highlights
3.  Key Topics, Definitions
4.  Key Concepts Emphasized
5.  Key Entities and Connected Relationships
6.  Key Chapters (if associated with table of contents as in a book)
7.  Key Applications and Use Cases mentioned (if relative)
8.  Key Action Items or Follow-Ups (if relative)
```
